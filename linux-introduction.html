Lesson objective

Understand Linux as a learning environment.

Linux is an open-source operating system family. It powers servers, cloud services, phones, network equipment, and many security tools.

Why it matters

Security learners use Linux because it is transparent, configurable, and widely used in the systems they will one day help protect.

  • Its terminal makes repeatable tasks fast and clear.
  • Its permissions model teaches good access-control habits.
  • Its open-source community provides excellent documentation.

First safe step

Start in a virtual machine before changing your main computer. This gives you a safe space to experiment, reset, and learn.
