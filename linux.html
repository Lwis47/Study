Linux operating systems

Find the right Linux distribution.

Linux distributions are versions of Linux packaged for different users and purposes. Use these official sites to learn more and download ISOs.

Beginner-friendly choices

Great places to begin.

These distributions are approachable, well documented, and useful for learning.

Ubuntu

A popular general-purpose Linux distribution with long-term support, extensive documentation, and a large community.

Official ISO download

Linux Mint

A comfortable desktop-focused distribution, especially suitable for people moving from Windows to Linux.

Official ISO download

Fedora Workstation

A polished workstation distribution with current open-source tools; ideal for developers and curious technical learners.

Official ISO download

Debian

A stable, community-driven distribution that forms the foundation for many other Linux systems, including Ubuntu.

Security-focused choices

Use only in legal labs.

These distributions include specialist security tools. Learn with them only on systems and networks you own or are authorized to test.

Kali Linux

A professional penetration-testing and digital-forensics distribution. Beginners should first use it in a virtual machine or legal lab.

Parrot OS

A privacy and security-focused Linux distribution available in both general-purpose and security editions.
